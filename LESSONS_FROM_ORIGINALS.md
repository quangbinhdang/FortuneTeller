# Lessons from Chinese Originals (English Translation Layer)

This file captures learned doctrine from Chinese-first source tradition.
Method: preserve original terms, then provide concise English gloss.

## 1) Zi Wei core doctrine (origin-school synthesis)

- `定盘` (chart fixing): correct birth-time and chart setup is foundational; interpretation before chart correctness is unreliable.
- `命宫` (Life Palace): central personality/life-axis anchor; always read with adjacent palace interactions, not isolation.
- `三方四正` (triad and opposite structure): evaluate a palace through its relational geometry; avoid single-point reading.
- `四化` (`化禄`, `化权`, `化科`, `化忌`):
  - `化禄`: resource/attraction gain tendency
  - `化权`: control/assertion/responsibility tendency
  - `化科`: refinement/reputation/ordering tendency
  - `化忌`: friction/obsession/blockage tendency
- `星曜` (star bodies): stars are symbolic operators; meaning shifts by palace position, transformations, and combinations.
- Non-determinism principle: many classical teachers (including modern lineages citing Zhongzhou practice) treat outcomes as tendencies shaped by timing + human decisions.

## 2) Yi Jing core doctrine (origin-commentary synthesis)

- `卦` (hexagram): pattern of a situation, not a fixed sentence.
- `爻` (line): dynamic position within the pattern; moving lines change interpretation priority.
- `象` (image): symbolic correspondence layer linking pattern to phenomena.
- `义理` (principle/meaning): moral-philosophical reading trajectory developed in major commentarial traditions.
- `变` (change): central ontology; interpretation requires phase-awareness, not static labels.

### Core reading sequence
1. Read the base hexagram (`本卦`) as context frame.
2. Inspect active/moving lines (`动爻`) for specific pressure points.
3. Derive transformed hexagram (`之卦`) for directional tendency.
4. Reconcile with `象` and `义理` to avoid literalism.

## 3) Textual fidelity caution

- Received `周易` text and excavated witnesses (e.g., Mawangdui silk manuscripts, bamboo slips) contain variants.
- Therefore, "single absolute wording" is historically unsafe; accuracy requires variant-aware interpretation notes.
