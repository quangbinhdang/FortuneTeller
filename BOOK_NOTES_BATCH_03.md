## Cross-tradition integration learned so far

### Shared high-confidence principles
1. Context beats single-factor readings.
2. Timing layers are mandatory for serious interpretation.
3. Deterministic/fatalist outputs are lower-quality methodology.

### Cross-system translation guardrails
- Western "natal potential" is not identical to Zi Wei palace/star grammar.
- Zi Wei/BaZi seasonal logic cannot be directly mapped onto tropical zodiac symbolism.
- Yi Jing hexagram change logic is process-structural, not personality-typing.
